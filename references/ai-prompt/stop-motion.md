# Stop-Motion

Claymation/puppet-animation look — tactile, handmade, slightly jittery motion.

## Vocabulary
- **Style descriptors:** stop-motion animation, claymation, felt/fabric puppet look,
  handmade miniature set, slight frame-to-frame jitter
- **Texture cues:** visible fingerprints in clay, visible stitching on fabric puppets,
  tangible miniature props

## Prompt template
```
Stop-motion claymation style, [original character description], [single action], on a
handmade miniature set of [setting], visible clay texture, slightly jittery frame-by-frame
motion, warm practical lighting
```

## Example
"Stop-motion claymation style, a round clay bird character hopping along a tiny handmade
branch, on a miniature forest set with felt leaves, visible clay texture and fingerprints,
slightly jittery frame-by-frame motion, warm practical lighting."

## Tips
- Explicitly asking for "slight jitter" or "frame-by-frame" motion is what sells the
  stop-motion feel — without it, models often default to smooth CG motion instead.
- Miniature-scale set details (visible seams, handmade props) reinforce the look more than
  the character design alone does.
- Simple, deliberate single actions (hop, turn, wave) match the stop-motion aesthetic better
  than fast or fluid motion.
