# 3D Animation

Stylized 3D character/world look — think modern animated feature or game cinematic, not photorealism.

## Vocabulary
- **Style descriptors:** 3D animated, Pixar-style, stylized render, game cinematic,
  claymation-adjacent CG, toon-shaded 3D
- **Lighting:** soft global illumination, rim light, bounce light, stylized color palette
- **Camera:** same cinematic vocabulary as live-action (push-in, orbit, tracking shot) —
  3D animation tolerates more dynamic camera moves than live-action does

## Prompt template
```
3D animated [character description, original — do not name existing franchises], [single
action], in [setting], [camera movement], [lighting], stylized render, vibrant color palette
```

## Example
"3D animated fox character with oversized ears wearing a patched backpack, hopping across
stepping stones over a stream, in a sunlit forest clearing, camera tracking alongside at
ground level, soft global illumination, stylized render, warm color palette."

## Tips
- Always describe an **original** character design — don't name existing animated
  franchises, studios, or characters (see the Copyright section in SKILL.md).
- 3D animation style tends to handle exaggerated motion (jumping, running, bouncing) better
  than live-action does — lean into that if the idea calls for energetic movement.
- Specify the color palette; stylized 3D reads much stronger with explicit color direction
  (e.g. "saturated primary colors" vs "muted pastel palette").
