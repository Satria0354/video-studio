# 2D Anime

Japanese animation look — cel-shaded, flat color, expressive motion lines.

## Vocabulary
- **Style descriptors:** 2D anime style, cel-shaded, hand-drawn animation look, flat color
  shading, anime key visual
- **Motion cues:** speed lines, impact frame, dramatic pose hold, wind-blown hair/clothing
- **Lighting:** flat cel lighting, dramatic backlight silhouette, sunset rim light

## Prompt template
```
2D anime style, [original character description], [single action], [setting], cel-shaded
flat color, [motion cue], [lighting], hand-drawn animation look
```

## Example
"2D anime style, a young swordsman with wind-blown hair standing on a cliff edge, drawing
their sword in one motion, mountain valley at sunset, cel-shaded flat color, dramatic
backlight silhouette, hand-drawn animation look."

## Tips
- Keep the character original (see Copyright section) rather than naming existing anime
  series or characters.
- Anime style tolerates dramatic, held poses and quick single actions well; it struggles
  with the same multi-action complexity every other genre does.
- Mentioning "flat color" / "cel-shaded" explicitly helps avoid the model defaulting to a
  3D-rendered or painterly look instead.
